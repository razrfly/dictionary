## Correction

The new immutable instruction `voltaire-whole-entry-v7` is a standalone,
lead-first evidence policy, rather than another appended clarification. It
requires evaluating entries and sense definitions before optional materials,
preserves applicable Bierce priority and honest abstention, treats personality
as a tie-breaker, and rejects title/name/retrieval matches as sufficient semantic
evidence. Descriptive supplied captions/headlines and quotation text may support
modest connections; sparse film/music/book/poem metadata does not reveal contents.

Dossier v8 preserves the sourced Voltaire dossier and changes only its template
version. No new persona is added. Packet/output remain runtime-packet-v4 and
selection-output-v4; 24 candidates, 12 meanings, section limits, 8K context,
1,024 output tokens, 120-second deadline and shared 30-minute daily budget remain.

Compact candidate evidence scopes and deduplicated rules are rendered in the
actual v7 user message, not merely JSON-schema descriptions. The prompt digest
and fit estimate include them. Schema descriptions also cue each candidate.
The full 24-candidate all-provider packet is tested against the unchanged context bound.
All v1–v6 instruction texts, their messages and schema semantics are unchanged;
the default helper still names v6. Only explicitly pinned v7 gets the new prompt.

**These are inference instructions, not semantic entailment enforcement.**
Exact IDs, meanings, source eligibility, expiry, quotes, binding/fences and
publication authority remain validated by the existing services. A plausible
but unsupported free-text reason can still pass structural validation. A test
makes this limitation explicit; no keyword classifier or automatic quality GO
has been invented. Native safety/injection abstention remains possible.

## Test-discovered date comparison repair

The full suite exposed an existing month-boundary bug: source-age selection used
structural DateTime ordering, choosing November 1 as older than October 29.
The oldest fetched timestamp and earliest next-refresh timestamp now use
chronological DateTime comparison. A fixed cross-month/year regression covers
both; source payloads, scheduling policy and the deployed trial remain unchanged.
