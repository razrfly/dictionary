The word page, three ways

Phase 1 of #131. Three whole-page layouts over the same two words, on the content the pages actually held on 2026-09-20. Nothing here is the app: every file is static HTML against the app's own stylesheet, built from its tokens and its components' classes.

Add ?theme=dark to any of these to see it dark. Every <details> opens.

All three apply the same rules to the same content — the same prose fold, the same card-level bound, the same metadata overflow, the same shelf templates — so what the comparison measures is placement, grouping and density rather than who folds harder.

The rest

  • The selected page — wide rail that scrolls away, opening on a reference source, with the research applied: prose at 752 px, historical sources labelled by period, counted disclosure labels, IMDb-style overflow tiles. Also nepotism.
  • Using the space — the selected rail rebuilt on the Oatmeal kit's own idioms: half-and-half grids, one accordion, stat tiles. The first round to reach the height budget.
  • The rail, five ways — variations on C, the selected direction: the same page held five different ways, changing only how each region is enclosed.
  • Hard cases — the five things neither love nor nepotism exercises: twelve pronunciations, sixty-six forms, five origins, a card holding 39,955 characters, and a shelf with nothing on it. Each one shown with the real word it comes from.
  • GIFs, three ways — #111's A, B and C on real results, and the in-viewport-versus-on-intent question answered.
