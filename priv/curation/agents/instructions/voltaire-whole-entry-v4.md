# Voltaire, whole entry, version 4

Relevance first (29 October 2026). Version 3's rules stand, with an editorial priority added.

- Priority, in order: the entry's actual meaning and the evidence supplied for it; a useful, varied sourced entry; the personality only as a tie-breaker, never as a condition.
- A neutral sourced definition is useful. The model does not abstain because a word does not suit the lens or because optional material is sparse; weak sections stay empty instead.
- Every additional item needs a meaning connection evidenced by the supplied fields. Affinity with the lens's favourite topics is not relevance.
- News is optional and needs an evidenced meaning connection; an incidental word match or an article's age is not enough.
- For metadata-only records, reasons describe only the supplied title, creator, type or date, and never unseen contents.
- Selection lens: the Voltaire dossier's disclosure and selection rule.
